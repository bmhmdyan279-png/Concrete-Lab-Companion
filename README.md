**نسخه ۳.۰.۰ – انتشار نهایی و کامل**

یک فایل اکسل حرفه‌ای، کاملاً خودکار و بدون ماکرو برای انجام محاسبات **۲۰ آزمایش استاندارد** فناوری بتن.  
طراحی شده بر اساس **ASTM** و **ISIRI**، با قابلیت **چاپ آماده**، **داشبورد**، **گزارش‌گیری خودکار**، **Golden Tests** و **ابزارهای QA** داخلی.

---

## ✨ ویژگی‌های برجسته نسخه ۳.۰.۰

- ✅ **بدون نیاز به ماکرو** – فقط داده‌ها را در سلول‌های زرد وارد کنید.
- ✅ **۲۲ شیت تخصصی** شامل تمام آزمایش‌های رایج سنگدانه، بتن تازه و بتن سخت‌شده.
- ✅ **جدول دانه‌بندی کامل** با ۸ الک استاندارد، درصد عبوری، حدود ISIRI 302 و نمودار لگاریتمی.
- ✅ **ضریب اصلاح L/D** در مقاومت فشاری (ASTM C39) برای نمونه‌های با نسبت ارتفاع به قطر کمتر از ۱.۸.
- ✅ **درصد هوای بتن** در آزمایش چگالی بتن تازه (ASTM C138).
- ✅ **فرمول استاندارد معادل ماسه** (SE = خوانش ماسه / خوانش رس × ۱۰۰) بر اساس ASTM D2419.
- ✅ **ارتفاع قالب اسلامپ** برابر با ۳۰۰ میلی‌متر (طبق ASTM C143M – نسخه متریک).
- ✅ **اصلاح چکش اشمیت** با ضرایب دما، زاویه و سطح (مرجع ACI 228.1R) و نمایش Disclaimer.
- ✅ **چیدمان ماتریسی** برای آزمایش‌های چندستونه (۲-۴ و ۴-۵).
- ✅ **شیت‌های مرجع** (`_Standards`, `_ISIRI_Limits`, `_Errata`, `_Validation_Data`).
- ✅ **Golden Tests** در شیت QA برای اعتبارسنجی خودکار فرمول‌ها.
- ✅ **گزارش نهایی** با خلاصه تمام نتایج، واحدها و وضعیت قبولی/هشدار/خطا.
- ✅ **داشبورد** برای پیگیری درصد تکمیل داده‌های ورودی.
- ✅ **حفاظت از شیت‌ها** (قابل غیرفعال‌سازی با `--no-protect`).
- ✅ **سازگار با اکسل آنلاین، موبایل و دسکتاپ**.
- ✅ **تولید خودکار با Python** – به‌روزرسانی آسان در آینده.

## 🚀 نحوه استفاده

### دانلود فایل اکسل

- جدیدترین نسخه را از **[بخش Releases](https://github.com/bmhmdyan279-png/Concrete-Lab-Companion/releases)** دانلود کنید.
- فایل `Concrete_Lab_Companion_v3.0.0.xlsx` را با اکسل (۲۰۱۶ یا بالاتر) باز کنید.

### ورود داده

- سلول‌های **زرد رنگ** را با مقادیر آزمایشگاهی پر کنید.
- بقیه سلول‌ها **قفل** هستند و محاسبات به‌صورت خودکار انجام می‌شود.

### مشاهده نتایج

- نتایج در سلول‌های **خاکستری** نمایش داده می‌شوند.
- وضعیت قبولی/هشدار/خطا با **رنگ‌های سبز، نارنجی و قرمز** مشخص شده است.

### چاپ گزارش

- شیت **گزارش** را انتخاب کنید و از منوی File → Print استفاده کنید.
- تنظیمات چاپ به‌صورت خودکار روی A4 افقی و متناسب با صفحه تنظیم شده است.

## 🛠 توسعه و ساخت مجدد (برای برنامه‌نویسان)

اگر می‌خواهید فایل اکسل را از کد منبع تولید کنید:

1. **پیش‌نیازها**: Python 3.10+ و کتابخانه `openpyxl`
2. نصب وابستگی‌ها:

   ```bash
   pip install -r requirements.txt
   ```

3. اجرای اسکریپت:

   ```bash
   python build.py
   ```

   فایل خروجی در پوشه `output/` ذخیره می‌شود.

### گزینه‌های خط فرمان

- `--no-protect` : غیرفعال کردن حفاظت شیت‌ها.
- `--demo` : پر کردن داده‌های نمونه برای نمایش.
- `--validate` : اعتبارسنجی رجیستری بدون ساخت فایل.
- `--output <dir>` : تعیین پوشه خروجی.

### تست خودکار (اختیاری)

برای اجرای تست‌های واحد (در صورت وجود):

```bash
pytest tests/
```
