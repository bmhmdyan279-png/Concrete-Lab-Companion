# 🧪 Concrete Lab Companion – همراه دیجیتال آزمایشگاه بتن

[![Build Status](https://github.com/bmhmdyan279-png/Concrete-Lab-Companion/actions/workflows/build.yml/badge.svg)](https://github.com/bmhmdyan279-png/Concrete-Lab-Companion/actions)

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC_BY--NC_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)

**یک فایل اکسل حرفه‌ای، کاملاً خودکار و بدون ماکرو** برای انجام محاسبات **۲۰ آزمایش استاندارد** فناوری بتن.
طراحی شده بر اساس **ASTM** و **ISIRI**، با قابلیت **چاپ آماده**، **داشبورد** و **گزارش‌گیری** خودکار.

---

## ✨ ویژگی‌های برجسته

- ✅ **بدون نیاز به ماکرو** – فقط کافی است داده‌ها را در سلول‌های زرد وارد کنید.
- ✅ **۲۲ شیت تخصصی** شامل تمام آزمایش‌های رایج سنگدانه، بتن تازه و بتن سخت‌شده.
- ✅ **محاسبات خودکار** با فرمول‌های تأییدشده بر اساس استانداردهای روز.
- ✅ **نمودار دانه‌بندی** با حدود استاندارد ISIRI 302 (لگاریتمی، قابل چاپ).
- ✅ **گزارش نهایی** با خلاصه تمام نتایج، آماده برای ارائه به کارفرما.
- ✅ **داشبورد** برای پیگیری پیشرفت و وضعیت کلی.
- ✅ **حفاظت از شیت‌ها** (با رمز `ConcreteLab2026!`) برای جلوگیری از تغییرات ناخواسته.
- ✅ **سازگار با اکسل آنلاین، موبایل و دسکتاپ**.
- ✅ **تولید خودکار** با Python – به‌روزرسانی آسان در آینده.

## 🚀 نحوه استفاده

### دانلود فایل اکسل

- جدیدترین نسخه را از **[بخش Releases](https://github.com/bmhmdyan279-png/Concrete-Lab-Companion/releases)** دانلود کنید.
- فایل را با اکسل (۲۰۱۶ یا بالاتر) باز کنید.

### ورود داده

- سلول‌های **زرد رنگ** را با مقادیر آزمایشگاهی پر کنید.
- بقیه سلول‌ها **قفل** هستند و محاسبات به‌صورت خودکار انجام می‌شود.

### مشاهده نتایج

- نتایج در سلول‌های **خاکستری** نمایش داده می‌شوند.
- وضعیت قبولی/هشدار/خطا با **رنگ‌های سبز، نارنجی و قرمز** مشخص شده است.

### چاپ گزارش

- شیت **گزارش** را انتخاب کنید و از منوی File → Print استفاده کنید.
- تنظیمات چاپ به‌صورت خودکار روی A4 افقی و متناسب با صفحه تنظیم شده است.

## 🛠 توسعه و ساخت مجدد (برای برنامه‌نویسان)

اگر می‌خواهید فایل اکسل را از کد منبع تولید کنید:

1. **پیش‌نیازها**: Python 3.10+ و کتابخانه `openpyxl`
2. نصب وابستگی‌ها:

   ```bash
   pip install -r requirements.txt
   ```

3. اجرای اسکریپت:

   ```bash
   python build.py
   ```

   فایل خروجی در پوشه `output/` ذخیره می‌شود.

### تست خودکار (اختیاری)

برای اجرای تست‌های واحد (در صورت وجود):

```bash
pytest tests/
```
